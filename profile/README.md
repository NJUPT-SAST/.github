# 各位好，这里是南邮校科协

南京邮电大学大学生科学技术协会（ Students’ Association for Science and Technology），简称校科协（SAST），曾名南京邮电学院大学生科学技术协会，成立于 1992 年。它是在校团委指导下依照国家法规和大学生规章制度，独立开展活动的学生科技文化及学术研究的组织，也是校团委直属社团中规模最大的技术类社团。

更多社团相关介绍请访问 [SAST 官网](https://sast.fun) 或阅读文档 [🖐️欢迎来到校科协](https://njupt-sast.feishu.cn/wiki/TbcJwtET4iCBweks34ycGSyonze?from=from_copylink)
